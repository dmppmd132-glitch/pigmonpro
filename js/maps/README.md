# 地圖資料

固定地圖格線集中在 `layouts.js` 的 `window.PIGMON_MAP_LAYOUTS` 物件。每個屬性名稱是地圖識別碼，每個陣列元素代表一列；字串中的每個字元就是一格。

## 修改現有地圖

找到對應識別碼（例如 `town`、`forestDeep` 或 `iceCave`），修改該地圖的列字串。一般地圖每列應維持相同寬度，並保留遊戲所需的入口、出口與特殊地形符號。

## 新增地圖

1. 在 `layouts.js` 新增新的識別碼與列陣列。
2. 在 `game.js` 將它加入可遊玩的 `MAPS`，並設定調色盤、入口／傳送點、遭遇或 NPC 等需要的遊戲邏輯。
3. 本機測試後提交到 `main`；GitHub Pages 會自動部署。

`game.js` 仍負責程式生成地圖、傳送點與事件、地圖互動以及執行時的格子變化；`layouts.js` 專注保存固定版型。
